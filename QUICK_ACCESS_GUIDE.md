## 📊 Sample Workflows

### **Workflow 1: Generate & Use a Wallet**

```text
1. Go to Blockchain Panel
2. Click "Generate Wallet" button
3. Select "Multi-Chain (All)" or specific chain
4. Click "Generate Wallet"
5. Copy and save the mnemonic (IMPORTANT!)
6. Copy an address (e.g., Ethereum address)
7. Scroll to "Blockchain Wallet Linking"
8. Select blockchain, paste address
9. Click "Link Wallet"
10. Now you can sync balances!
```

### **Workflow 2: Check Any Address**

```text
1. Go to Blockchain Panel
2. Find "Blockchain Balance Checker"
3. Select network (Ethereum/BSC/Solana/TRON)
4. Paste any address
5. Click "Check Balance"
6. See real blockchain data!
```

### **Workflow 3: Create & Execute Order**

```text
1. Go to Trading Panel
2. Scroll to "Advanced Exchange Orders"
3. Fill in order details:
   - Label: "My BTC order"
   - From: BTC
   - To: ETH
   - Amount: 0.001
   - Target Rate: (current rate)
   - Trigger: <= or >=
4. Click "Create Order"
5. Click "Process Open Orders" to execute
```

### **Workflow 4: Connect MetaMask**

```text
1. Install MetaMask extension
2. Go to Trading Panel
3. Click "Connect EVM Wallet"
4. Approve in MetaMask popup
5. Click "Import Connected" to link address
6. Address is now linked to your account!
```

### **Workflow 5: Test APIs**

```text
1. Go to Plugin APIs Panel
2. Click any row (e.g., "/api/rates")
3. Click "Run Selected"
4. View JSON response below
5. Try adding custom query parameters
6. Create your own endpoints!
```
