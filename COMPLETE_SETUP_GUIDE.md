## 🚀 How to Start the Application

### Option 1: Standard Start

```powershell
cd d:\crypto\crypto-exchange-app
npm start
```

### Option 2: Development Mode (with auto-restart)

```powershell
cd d:\crypto\crypto-exchange-app
npm run dev
```

### Option 3: Using VS Code Tasks

Press `Ctrl+Shift+P` and select:

- "Tasks: Run Task" → "Start App (npm start)"
- OR "Tasks: Run Task" → "Start Dev (npm run dev)"
